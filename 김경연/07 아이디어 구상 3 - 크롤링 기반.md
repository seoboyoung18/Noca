# SNS 게시물 맥락 검증 서비스

## 아이디어

SNS 게시물의 캡처 이미지와 주장 텍스트를 입력하면, 뉴스·공식 자료 아카이브에서 관련 근거와 유사 이미지를 찾고, 해당 정보의 출처 후보와 맥락 변화 과정을 제공하는 서비스

> 전체 웹의 최초 출처나 게시물의 진위를 단정하지 않고, 수집한 아카이브에서 확인된 출처 후보·이미지 사용 이력·후속 및 정정 자료를 제공한다.
> 

## 문제 상황

SNS에서는 뉴스 이미지나 주장이 **출처 및 원래 맥락과 분리된 채 재유통**되는 경우가 있다. 사용자가 근거를 확인하기 위해 검색해도 최신·중복 기사 위주로 노출되어 어떤 정보에서 시작됐고 이후 어떻게 추가·정정됐는지 파악하기 어려워, 사용자가 직접 기사별 날짜·내용·출처를 비교해야 한다.

## 핵심 기능

1. **게시물 분석**
    - 캡처에서 사진 영역 분리
    - OCR로 주장 추출
    - 날짜·장소·사건 및 출처 단서 파악
2. **관련 자료 검색**
    - 뉴스·공식 자료 수집
    - 관련 기사와 근거 문단 검색
3. **유사 이미지 검색**
    - 이미지 해시와 임베딩으로 후보 검색
    - 크롭·압축·자막이 추가된 이미지까지 비교
4. **출처 탐색 및 타임라인**
    - 중복·유사 기사를 사건 단위로 묶어 정리
    - 아카이브 내 최초 확인 자료 → 공식 발표 → 후속·정정 보도 제공
    - 게시물 주장과 자료의 시간·장소·사건 및 변경 내용 비교

## 결과 예시

> 해당 내용은 우리 아카이브에서 2026년 8월 20일 지역 언론 기사에 가장 먼저 나타납니다. 이후 공식 발표에서 초기 피해 규모가 정정되었지만, SNS 게시물에는 정정 전 내용이 사용되고 있습니다.
> 

결과는 다음과 같이 제공한다.

- 출처 및 관련 근거 확인
- 일부 맥락 생략·변경 가능성
- 판단 불충분

## 기술 구성

```
SNS 캡처·주장 입력
→ 사진 분리 및 OCR
→ 뉴스·공식 자료 검색
→ 유사 이미지·중복 기사 검색
→ 시간·장소·사건 및 정보 변화 비교
→ 근거와 타임라인 제공
```

- 빅카인즈·RSS·Selenium: 뉴스 및 이미지 수집
    
    https://www.gov.kr/portal/service/serviceInfo/B55264800033
    
- Spark: 대규모 전처리·임베딩·중복 제거
- pHash·CLIP·특징점 매칭: 변형 이미지 검색
- Vector DB: 유사 이미지·관련 문단 검색
- LLM: 주장과 기사에서 날짜·장소·사건 및 변경 내용 추출

## 차별점

구글 렌즈보다 많은 이미지를 찾는 것이 아니라, **이미지 검색 결과와 게시물의 텍스트 주장을 결합하고 중복 기사를 사건 단위로 정리하여, 정보의 출처 후보부터 공식 발표·후속·정정 보도까지의 맥락을 자동으로 제공**한다.

## MVP

세부 도메인은 데이터 확보 가능성, 출처가 생략된 게시물의 빈도, 공식 자료 존재 여부를 검토해 회의에서 결정한다.

- 입력: SNS 캡처 또는 이미지＋주장
- 출력: 아카이브 내 가장 이른 등장 후보, 관련 기사, 중복 기사 묶음, 사건 타임라인
- 평가: 실제 출처 생략·이미지 재사용·정보 정정 사례를 직접 구축해 `Recall@K`, 중복 기사 군집화 정확도, 날짜·장소 추출 정확도 평가

## 고려사항

- ‘인터넷 최초 출처’가 아니라 **‘우리 아카이브에서 확인된 가장 이른 등장’**으로 표현
- 게시물을 ‘허위’라고 단정하지 않고 확인된 출처·변경·불일치 근거만 제공
- 뉴스 전문·이미지 저작권을 고려해 링크·메타데이터·최소 인용 중심으로 제공
- 도메인 확정 전 기사와 이미지의 실제 수집 가능성을 먼저 검증해야 함

## 아이디어

블로그 후기에서 AI 작성 여부나 진위를 판별하는 대신, **구체적인 경험 정보가 있고 복제·광고성 신호가 적은 글을 우선적으로 보여주는 서비스**

> “사람이 쓴 글”이 아니라 “먼저 읽을 가치가 있는 글”을 찾는 것이 목적
> 

## 문제 상황

협찬 후기와 복제·양산형 콘텐츠가 증가하면서 실제 경험이 담긴 후기를 찾기 어려워졌다. 따라서 작성 주체를 추측하지 않고, 글에서 확인 가능한 **경험·중복·상업성 신호**를 분석한다.

## 핵심 기능

1. **양산형 콘텐츠 탐지**
    - 유사·반복 문장 및 재사용 이미지 탐지
    - 표현만 바꾼 글 군집화
    - 특정 제품의 유사 글이 단기간에 집중된 패턴 확인
2. **경험 정보 추출**
    - 가격·날짜·사용 기간 등 구체적인 정보 추출
    - 사용 환경, 장단점, 실패·수리·후속 경험 구분
3. **광고·협찬 신호 확인**
    - 협찬·원고료·제품 제공 문구 탐지
    - 제휴 링크와 수수료 표시 확인
    - 동일 제품 글의 반복 문장·이미지 비교

## 결과 예시

```
읽을 가치: 높음

✓ 1년 5개월 사용 기간 및 고장 경험 포함
✓ 구체적인 장점과 단점 포함
✓ 다른 글과 문장·이미지 중복 낮음

! 제휴 링크 포함
! 동일 제품의 유사 글 8건 동시 게시

실제 구매 여부와 내용의 진위는 확인되지 않습니다.
```

## 기술 구성

```
후기 사전 수집
→ 본문·이미지 전처리
→ 중복·재사용 분석
→ 경험·협찬 신호 추출
→ 검색 결과 재정렬
```

- RSS·API·Selenium: 공개 게시글 수집
- Spark: 대규모 배치 전처리
- MinHash/LSH·문장 임베딩: 유사 문서 탐지
- pHash·이미지 임베딩: 재사용 이미지 탐지
- LLM: 가격·기간·장단점 등 경험 정보 추출
- Vector DB: 유사 글·이미지 검색

## 차별점

기존 AI 탐지처럼 작성 주체를 추측하지 않고, **구체적인 경험 정보, 텍스트·이미지 중복, 동시 게시 패턴, 협찬 표시 등 사용자가 확인할 수 있는 근거를 함께 제공**한다.

## MVP

데이터 수집 가능성을 조사한 뒤 전자제품, 자동차 또는 맛집·숙소 중 한 분야를 선정한다.

- 입력: 검색어 또는 기존 검색 결과
- 출력: 경험 정보·중복·협찬 배지
- 서비스: 브라우저 확장 프로그램 또는 검색 웹
- 미수집 글: `분석 범위 밖`으로 표시

- 중복 문서·재사용 이미지 탐지 정확도
- 경험 정보·협찬 표시 추출 F1

- 플랫폼 이용약관과 저작권을 확인하고 원문 대신 링크와 분석 결과 제공

## 아이디어

중고거래 플랫폼의 텍스트와 이미지를 분석해 **실제 티켓 재판매 게시물을 찾고, 공연·좌석·가격 정보를 복원하여 공연별 재판매 현황을 제공하는 서비스**

> 암표나 법 위반 여부를 판정하지 않고, 공개 게시물에서 관찰된 정보만 제공한다.
> 

## 문제 상황

티켓 재판매 게시물은 일반적인 키워드·가격 검색만으로 정확히 분석하기 어렵다.

- 굿즈나 동명의 일반 상품이 함께 검색됨
- `61원`, `99,999원` 등 실제와 다른 등록가격 사용
- `장당 17`, `티포 21`처럼 가격 단위 생략
- 가격·좌석 정보를 이미지에만 표시
- 정확한 가격을 공개하지 않고 채팅 문의 유도

## 핵심 기능

### 1. 재판매 게시물 탐색

- 티켓 카테고리 게시물 수집
- 키워드 검색으로 카테고리 밖 게시물 추가 탐색
- 텍스트와 이미지로 티켓·굿즈·일반 상품 분류

### 2. 거래정보 복원

- 공연·회차·좌석·매수 추출
- 축약 가격을 실제 금액 후보로 정규화
- 형식상 등록가격과 가격 문의 게시물 구분
- OCR·VLM으로 이미지에만 있는 정보 추출
- KOPIS·예매처 정보와 연결하여 정가 비교

### 3. 유통 변화 분석

- 관측된 재판매 게시물 수
- 정가 대비 가격 분포
- 가격 미표시·형식상 가격 비율
- 카테고리 밖 게시물 비율
- 공연일 접근에 따른 가격 변화
- 게시물 최초·마지막 관측 시점

## 처리 구조

```
카테고리·키워드 기반 주기적 수집
→ 티켓 게시물 멀티모달 분류
→ 공연·좌석·가격 정보 추출
→ 공연 정보 및 정가 연결
→ 시계열 저장
→ 공연별 대시보드 제공
```

## 멀티모달이 필요한 이유

거래정보가 제목·본문·등록가격·이미지에 나뉘어 있기 때문이다.

```
본문: “막콘 2연 양도, 가격은 사진 참고”
이미지: 공연 포스터＋VIP F5구역＋25
```

텍스트와 이미지를 결합해야 실제 티켓 게시물인지 구분하고 부족한 거래정보를 복원할 수 있다.

## 결과 예시

```
가상 콘서트 / 9월 12일 / R석

등록가격: 61원
추출가격: 장당 170,000원
가격 근거: 본문 “R석 장당 17”
정가 대비: 1.4배

※ 법 위반 여부는 판정하지 않습니다.
```

## MVP

- 성격과 공연일이 다른 공연 3개 선정
- 중고거래 플랫폼 1개＋티켓 전문 플랫폼 1개
- 티켓 게시물 분류 및 거래정보 추출
- 정가 대비 가격·가격 미표시·시계열 변화 대시보드
- 텍스트 단독 대비 멀티모달 정보 완성률 비교

## 고려사항

- 전체 시장이 아닌 공개 페이지에서 관측된 게시물 기준
- 게시물 소멸을 실제 판매 완료로 단정하지 않음
- 개인정보를 마스킹하고 원본 이미지는 영구 저장하지 않음
- 플랫폼 이용약관과 자동수집 허용 범위 확인 필요
