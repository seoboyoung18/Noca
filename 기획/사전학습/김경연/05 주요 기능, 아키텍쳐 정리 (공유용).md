# 05 주요 기능, 아키텍쳐 정리 (공유용)

날짜: 2026년 8월 25일
다중 선택: 설계

## 기능

```jsx
[사용자 차량 이미지]
        ↓
① 파손 분석 AI
        ↓
부품 + 손상 유형
        ↓
② 유사 사례 검색 AI
        ↓
유사 과거 사례 Top-K
        ↓
③ 예상 수리비 산출
        ↓
[부품별 예상 수리 방법 + 비용 범위]
```

| 기능 | Input | 처리 | Output |
| --- | --- | --- | --- |
| **1. 차량 파손 분석 AI** | 사용자 차량 이미지  | 부품·손상 탐지 | `앞범퍼 / 긁힘·찌그러짐` |
| **2. 유사 사고 사례 검색 AI** | 파손 부위 이미지 + 1번 결과 | 임베딩 생성 → Vector DB Top-K 검색 | 유사 파손 사례 + `case_id` |
| **3. 예상 수리비 산출** | 유사 사례 `case_id` + 부품/수리방법 | Cost DB 조회 → 비용 통계 → 현재 가격 보정 | `앞범퍼 수리·도장 예상 55~68만원` |

## 요약 아키텍쳐

```jsx
                    HDFS
              원본 데이터 저장
                    ↓
              Spark 등으로 가공
                    ↓

        ┌───────────┴───────────┐
        ↓                       ↓
    Vector DB                 Cost DB
    ---------                 -------
    이미지 임베딩              수리비
    case_id                   case_id
    part                      part
    damage                    repair
                              cost
```
