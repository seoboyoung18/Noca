날짜: 2026년 8월 18일
다중 선택: 학습

# 방법

1. **Batch 처리**

이미 쌓인 대용량 데이터를 처리한다.

```
지난 1년 제조 데이터 5TB
        ↓
      Spark
        ↓
공정별 불량률 / 패턴 / 통계 계산
```

1. **Streaming 처리**

데이터가 계속 들어오는 상황에서 실시간으로 처리한다.

```
Sensor
 ↓
Kafka
 ↓
Spark Structured Streaming
 ↓
실시간 집계/이상 판단
 ↓
DB / Dashboard
```

# 도구

**Kafka**

> 데이터가 너무 빠르게 들어온다.
> 
> 
> → 일단 안정적으로 받고 분산시킨다.
> 

**Spark**

> 받은 데이터의 계산량이 너무 많다.
> 
> 
> → 여러 Worker가 나눠 계산한다.
>

# 레퍼런스

### 실시간 줄서기 서비스

```jsx
사용자 → Spring 서버 → PostgreSQL / Redis
              │
              │ 서비스 이용 로그 발생
              ↓
           Flume
        로그 수집/전송
              ↓
            HDFS
       대량 로그 장기 저장
              ↓
            Hive
        SQL로 조회/집계
              ↓
       이용 패턴 분석
```

실시간 서비스가 있고 → 사용자가 많아질수록 로그가 대량으로 발생하고 → 그 로그를 서비스 DB와 별도로 수집하고 → Hadoop에 축적하고 → Hive로 대규모 분석한다.
