# 1. 폐의류 분산 선별 및 AI 재활용 의사결정 플랫폼
## 아이디어 개요

- 대규모 폐의류 이미지를 HDFS에 분산 저장하고 MapReduce로 병렬 전처리·분석한 뒤, Vision AI를 활용해 폐의류의 처리 방법을 자동 결정하고 선별 현장의 운영 인사이트까지 제공하는 시스템
- 문제 상황: 폐의류 선별 현장에서는 의류가 계속 유입되고, 작업자가 각각의 의류를 확인해 재사용·재활용·폐기 여부를 판단해야 함
- 대량의 폐의류에 대해서 기존에는 사람의 육안 선별에 의존하고, 손상 및 오염, 부착물 등 세부 상태 판단이 어려움
- 폐의류 이미지를 HDFS에 분산 저장하고 MapReduce를 활용해 대규모 이미지 데이터를 병렬 전처리 및 집계
- 이후 Vision AI를 통해 폐의류의 종류와 상태를 분석하고, 재사용·재활용·폐기 여부를 결정
- 축적된 선별 결과를 다시 분산 분석하여 의류 유형별 재활용률, 손상·오염 패턴, 폐기 원인 등을 제공

# 2. Hadoop 기반 AI 사내 문서 통합 관리 및 지능형 검색 시스템
## 아이디어 개요

- 기업에 축적되는 대규모 문서를 HDFS에 통합 저장하고 MapReduce로 분산 처리하여 문서 구조·내용을 자동 분석하고, AI 기반 의미 검색·유사 문서 탐색·요약을 제공하는 문서 관리 시스템
- 문제 상황: 기업에서 문서가 많아질수록 단순한 파일명/폴더 기반 관리로는 원하는 정보를 찾기 어려움, 기업 문서는 수년, 수십년 간 지속적으로 누적
1. 통합 문서 아카이빙
    - 기업에서 발생하는 문서를 HDFS에 저장한다고 가정
    - 문서 자체 뿐만 아니라 문서와 관련된 메타데이터까지 함께 관리
2. 문서 내용 분석
    - 문서 키워드/메타데이터를 추출하고 집계하여 트렌드 분석 진행
    - 내용이 거의 같지만 파일명만 다른 문서에 대해 유사도 검사를 통해 관리 효율화
    - 자연어 문서 검색 기능
- AI hub의 데이터셋을 기업용 Document Lake의 프로토타입 데이터셋으로 가정

# 6. K-뷰티 헤어스타일 이미지 분산 분석 및 맞춤형 헤어 추천 플랫폼
## 아이디어 개요

- 50만 장의 헤어스타일 이미지를 HDFS에 분산 저장하고 MapReduce로 이미지·메타데이터를 일괄 처리한 뒤, AI/Vision 모델을 이용해 고객의 헤어스타일을 분석하고 유사 스타일·시술 결과·관리 정보를 추천하는 시스템
- 헤어스타일에 관심이 많은 사람 또는 K-뷰티에 관심이 많은 외국인 관광객을 타겟으로 서비스를 제공
- Map 단계에서 다음 작업 수행
    - 이미지 무결성 검사
    - 해상도 통일
    - 헤어 영역 crop
    - segmentation 기반 background 제거
    - 색상 정규화
    - 메타데이터 매칭
- Reduce 단계에서 다음 작업 수행
    - 스타일 별 이미지 수
    - 성별 별 스타일 분포
    - 연령대 별 스타일 분포
    - 시술 전/후 데이터 수
    - 헤어 컬/길이 별 분포
- 사용자 얼굴 이미지를 기반으로 컬 종류 × 앞머리 × 길이 조합을 출력하여 스타일 추천
- 추가적으로 시기 별로 어떤 헤어스타일이 많이 등장하는지 트렌드를 분석하여 추천에 제공해주는 방안

- 대규모 농경지 초분광 데이터를 분산 처리하여 작물 분포와 재배면적을 산출하고, 지역·작물·생육단계별 농업 현황을 제공하는 시스템

    - Spectral-Spatial CNN
    - SpectralFormer
    - Transformer 계열
    - U-Net/DeepLab 계열의 hyperspectral segmentation 변형
- 농작물 병충해 위험지역 분석 시스템으로도 확장 가능
- 각 모듈의 역할
    - Hadoop → 초분광 데이터 전처리
        - 정규화
        - 노이즈 제거
        - 품질 검사
        - 메타데이터 정제
        - 작물별 / 지역별 / 촬영별 training data grouping
    - AI → 작물/병충해/생육단계 예측

# 8. 차량 사고 빅데이터 이미지 기반 예상 수리 견적 조회 서비스

    - 차량 파손 이미지 데이터에 대해 Hadoop 기반 분산 전처리 및 Vector DB에 특징 정보 저장
    - 파손 정보, 수리 내역, 비용과 관련된 메타데이터 정보 저장
    - 사용자가 이미지를 입력하면 Vector DB에서 유사도 검색을 진행한 후 예상 견적 산출
