# 한 줄에 한 단어. '#' 로 시작하는 줄과 빈 줄은 무시한다.
#
# application.properties 가 아니라 이 파일에 두는 이유 — Spring Boot 는 .properties 를
# ISO-8859-1 로 읽어서(java.util.Properties 규약) 한글 값이 깨진다. 이 파일은 UTF-8 로
# 직접 읽는다. 목록을 고칠 때 코드를 건드리지 않아도 되는 건 그대로다.
#
# 판정 규칙 — 비교 전에 공백·특수문자를 지우고 소문자로 맞춘 뒤 부분 문자열로 본다.
# 따라서 "시 발", "시.발", "ADMIN" 도 걸린다. 여기에는 기본형만 적으면 된다.

# 초성 우회(ㅅㅂ)는 일부러 잡지 않는다 — "수박·소방·신발"의 초성이라
