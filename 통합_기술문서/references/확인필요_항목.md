# 확인필요 항목

## 목적

전체 문서의 `확인 필요 항목` 을 한곳에 모은다. **"확인 안 됨" 은 "문제 있음" 이 아니라
"현재 작업공간에서 근거를 찾지 못함" 이다.**

## 공백의 뿌리

확인하지 못한 항목의 대부분이 **네 가지 원인**에서 나온다.

```mermaid
flowchart TB
    R1["① Nginx 설정이 저장소에 없다"]
    R2["② IaC가 없다"]
    R3["③ 환경변수 실제 값은 서버·CI에 있다"]
    R4["④ GitLab MR·전체 Jira에 접근하지 못했다"]

    R1 --> E1["TLS · 도메인 · 프록시 · SPA 폴백<br/>보안 헤더 · 캐시 · 압축 · 로그"]
    R2 --> E2["서버 종류(EC2/Lightsail) · 스펙<br/>방화벽 · VPC · S3 정책 · IAM"]
    R3 --> E3["버킷 이름 · 도메인 · 토큰<br/>워커 스위치 운영값"]
    R4 --> E4["작업 이력 완전성 · 담당자 분담"]
```

**①②를 저장소로 가져오면 절반 이상이 해소된다.**

## 🔴 우선 확인 (데이터·보안 직결)
