# 요청 처리 시퀀스

## 목적

프론트엔드 → 백엔드 → AI 서버로 이어지는 요청 흐름을 시퀀스로 그린다.

## ① 로그인

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as Vue SPA
    participant BE as Spring Boot
    participant OA as 카카오/구글
    participant RD as Redis

    U->>FE: 로그인 버튼
    FE->>FE: sessionStorage에 복귀 경로 저장<br/>noka.auth.next
    FE->>BE: GET /oauth2/authorization/{kakao|google}
    BE-->>U: 제공자 인가 페이지로 리다이렉트
    U->>OA: 동의
    OA->>BE: GET /login/oauth2/code/{provider}
    BE->>OA: 토큰 교환 · 프로필 조회
    alt 기존 회원
        BE->>RD: 세션 생성 (ROLE_USER)
    else 신규
        BE->>RD: 세션 생성 (ROLE_SIGNUP_PENDING)
    end
    BE-->>FE: FE 루트(/)로 리다이렉트 + SESSION 쿠키
    FE->>BE: GET /api/auth/me
    alt ROLE_SIGNUP_PENDING
        BE-->>FE: 403 SIGNUP_REQUIRED
        FE->>FE: onAuthError → 약관·가입 화면
        FE->>BE: POST /api/auth/signup
        BE->>RD: 역할 승격 (ROLE_USER)
    else ROLE_USER
        BE-->>FE: 200 회원 정보
        FE->>FE: noka.auth.next 로 복귀
    end
```

## ② 일반 조회 요청

```mermaid
sequenceDiagram
    participant FE as Vue SPA
    participant NG as Nginx
    participant SEC as Spring Security
    participant CT as Controller
    participant SV as Service
    participant DB as PostgreSQL
    participant RD as Redis

    FE->>NG: GET /api/accidents/me<br/>Cookie: SESSION (withCredentials)
    NG->>SEC: 프록시 (127.0.0.1:8080)
    SEC->>SEC: CORS 오리진 확인
    SEC->>RD: 세션 조회 → 역할
    SEC->>SEC: 경로 매처 인가 (hasAnyRole USER/ADMIN)
    alt 인가 실패
        SEC-->>FE: 401 / 403
    end
    SEC->>CT: 통과
    CT->>SV: 위임
    SV->>DB: 소유자 조건 포함 조회
    DB-->>SV: 결과
    SV-->>CT: DTO
    CT-->>FE: 200 { "data": { ... } }
```

## ③ 사진 업로드 3단계

```mermaid
sequenceDiagram
    actor U as 사용자
    participant FE as UploadView.vue
    participant BE as Spring Boot
    participant S3 as Amazon S3
    participant DB as PostgreSQL

    U->>FE: 사진 선택
    FE->>FE: 타입·크기 사전 검사<br/>jpeg/png · 20MB
    Note over FE: state = 'issuing'
    FE->>BE: POST /api/accidents/{id}/images/upload-urls
    BE->>BE: 소유자 검사 + 키 생성 (서버만)<br/>accidents/{id}/images/{imageId}/original.jpg
    BE->>S3: presigned PUT URL 생성
    BE-->>FE: { uploadUrl, ... }
    Note over FE: state = 'uploading'
    FE->>S3: PUT (파일 바이트 — 백엔드 경유 안 함)
    S3-->>FE: 200
    Note over FE: state = 'completing'
    FE->>BE: POST /api/accidents/{id}/images
    BE->>S3: HeadObject 확인
    BE->>S3: 원본 읽기
    BE->>BE: RESIZED · THUMBNAIL 생성 (EXIF 제거)
    BE->>S3: 변형 저장
    BE->>DB: accident_image + accident_image_asset × 3
    BE-->>FE: 완료
    Note over FE: state = 'done'
```

## ④ 분석 요청 → 콜백 (핵심 경로)

```mermaid
sequenceDiagram
    participant FE as Vue SPA
    participant BE as Spring Boot
    participant W as AnalysisRequestWorker
    participant DB as PostgreSQL
    participant S3 as Amazon S3
    participant AI as FastAPI

    FE->>BE: POST /api/accidents/{id}/analysis
    BE->>DB: analysis_job INSERT (status=QUEUED)
    BE-->>FE: 접수 응답

    Note over W: @Scheduled 폴링
    W->>DB: UPDATE status=PROCESSING WHERE status=QUEUED<br/>(조건부 · 부분 UNIQUE 로 중복 차단)
    W->>S3: RESIZED presigned GET URL 발급
    W->>AI: POST /analyze<br/>X-Internal-Token<br/>{jobId, requestId, vehicle, images[], callbackUrl}
    AI-->>W: 202 { accepted, jobId, requestId }

    Note over AI: 백그라운드 처리
    AI->>S3: GET 이미지 (presigned)
    AI->>AI: YOLO part(detect) + damage(segment)
    AI->>AI: 기하 매칭 → PAIRED/UNPAIRED
    AI->>AI: ROI 20% padding → 224 letterbox
    AI->>AI: DINOv2 768d → L2 정규화
    AI->>DB: pgvector 검색 (MODEL→PRICE_TIER→ALL, 읽기 전용)
    AI->>DB: repair_case 비용 조회
    AI->>AI: 견적 산출

    loop 최대 4회 (0·1·5·20초)
        AI->>BE: POST /internal/analysis-jobs/{jobId}/result<br/>X-Internal-Token · X-Request-Id
        BE->>BE: ① 헤더 == 본문 requestId ?
        BE->>BE: ② 경로 == 본문 jobId ?
        BE->>DB: 작업 조회
        BE->>BE: ③ 저장된 requestId 일치 ?
        alt 이미 완료
            BE-->>AI: 200 duplicate=true (저장 생략)
        else 정상
            BE->>DB: analysis_image_result · estimate · estimate_item
            alt 모든 사진 제외
                BE->>DB: markFailed(ALL_IMAGES_EXCLUDED)
            else
                BE->>DB: markCompleted
            end
            BE-->>AI: 200 duplicate=false
        end
    end

    loop 2초 주기 폴링
        FE->>BE: GET /api/accidents/{id}/analysis
        BE-->>FE: { totalStages, doneStages, currentStage, excludedImages }
    end
    FE->>BE: GET /api/accidents/{id}/analysis/result
    BE-->>FE: { images[{ excluded, exclusionReason, detections[] }] }
```

## ⑤ 비동기 작업 공통 패턴

분석·견적 PDF·체크리스트가 모두 이 모양이다.

```mermaid
sequenceDiagram
    participant FE
    participant CT as Controller
    participant DB
    participant W as @Scheduled Worker
    participant EX as 외부 (AI·GMS·S3)

    FE->>CT: POST .../{작업}
    CT->>DB: 작업 행 INSERT (QUEUED)
    CT-->>FE: 즉시 응답
    loop 주기
        W->>DB: 조건부 UPDATE → PROCESSING
        W->>EX: 외부 호출
        alt 성공
            EX-->>W: 결과
            W->>DB: 결과 저장 + COMPLETED
        else 실패 (재시도 한도 내)
            W->>DB: QUEUED 복귀 + retry_count++
        else 실패 (한도 초과)
            W->>DB: FAILED + ABANDONED
        end
    end
    loop 폴링
        FE->>CT: GET .../{작업}
        CT-->>FE: 상태
    end
```

**반복 실패를 큐에 되돌리지 않는다** — "영영 실패하는 건이 매 주기 GMS 크레딧을 태운다."

## ⑥ 오류 전파

```mermaid
sequenceDiagram
    participant FE
    participant BE
    participant AI
    participant DB

    AI->>AI: ModelRunError 발생
    AI->>BE: 콜백 { error: { code: "MODEL_ERROR", retryable: true } }
    BE->>DB: analysis_job.failure_reason = 'MODEL_ERROR'
    BE-->>AI: 200
    FE->>BE: GET /api/accidents/{id}/analysis (폴링)
    BE-->>FE: { status: FAILED, failureReason: 'MODEL_ERROR' }
    FE->>FE: FAIL_TEXT['MODEL_ERROR']
    FE-->>FE: "AI 분석 중 오류가 발생했어요. 잠시 후 다시 시도해 주세요."
```

**오류 코드가 DB를 거쳐 화면 문구가 된다.** 한글 문안은 코드에 넣지 않는다 —
"사용자에게 보일 문구는 화면이 이 코드를 보고 정한다."

## 확인 필요 항목

- **Nginx 프록시 단계** — 설정이 없어 `/api` 경로 처리를 확인하지 못함
- **업로드 URL 발급 요청·응답 본문** — DTO를 확인하지 못함
- **워커 폴링 주기** — `fixedDelay` 값을 확인하지 못함
- **RESIZED 생성 시점** — 완료 통보 처리 중 동기 생성으로 추정
