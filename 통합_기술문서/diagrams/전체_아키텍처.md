# 전체 아키텍처 다이어그램

## 목적

시스템 구성을 한 장에 담는다. 서비스명·포트·경로는 **설정 파일에서 확인한 값**이며,
확인하지 못한 것은 표시했다.

## 시스템 구성도

```mermaid
flowchart TB
    U["사용자<br/>모바일 웹 브라우저"]

    subgraph BEBOX["BE 박스 · 172.26.8.28"]
        NGX["Nginx<br/>:80 / :443 (확인 필요)"]
        WEB["/var/www/a307<br/>Vue 3 빌드 산출물"]
        BE["a307-backend<br/>Spring Boot 4.1.1 / Java 21<br/>127.0.0.1:8080 · 172.26.8.28:8080"]
    end

    subgraph AIBOX["AI 박스 · 172.26.4.46"]
        AI["a307-ai<br/>FastAPI 0.115 / Python 3.12<br/>172.26.4.46:8000<br/>mem 6g · cpu 3"]
        DB[("a307-db<br/>PostgreSQL 16 + pgvector<br/>47 tables")]
    end

    RD[("Redis 7<br/>Spring Session<br/>a307:session · 30m")]

    subgraph EXT["외부 서비스"]
        S3["Amazon S3<br/>staging · service 버킷<br/>ap-northeast-2"]
        OA["카카오 / 구글<br/>OAuth2"]
        KM["카카오 지도 SDK"]
        GMS["SSAFY GMS<br/>LLM 프록시"]
    end

    U -->|HTTPS| NGX
    NGX --> WEB
    NGX -->|프록시 · 확인 필요| BE
    U -->|presigned PUT| S3
    U -.->|SDK 직접 호출| KM
    U -.->|로그인 리다이렉트| OA

    BE --> RD
    BE --> DB
    BE -->|presigned URL 발급| S3
    BE -->|POST /analyze<br/>X-Internal-Token| AI

    AI -->|presigned GET| S3
    AI -->|읽기 전용| DB
    BE -->|HTTPS| GMS
    BE -.->|토큰 교환| OA
```

```mermaid
flowchart LR
```

```mermaid
    subgraph OFF["오프라인"]

        PIPE --> ROI2["ROI 추출"]
        ROI2 --> EMB2["DINOv2 768d"]

    end
    SRCH --> CORP
    CORP --> RES["유사 사례 Top-K"]
```

**`shared/vision` 이 양쪽에 같은 전처리를 보장한다.** 갈라지면 오류 없이 결과만 틀린다.
