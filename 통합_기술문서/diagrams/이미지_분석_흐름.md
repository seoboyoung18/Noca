# 이미지 분석 흐름 다이어그램

## 목적

사진 한 장이 견적이 되기까지의 변환을 단계별로 그린다.

## 전체 파이프라인

```mermaid
flowchart TB
    A["① RESIZED 이미지<br/>presigned GET 다운로드"]
    B1["② part 모델<br/>vehicle-part-detection<br/>32 클래스 · bbox"]
    B2["② damage 모델<br/>vehicle-damage-segmentation<br/>4 클래스 · polygon"]
    C["③ raw JSON 검증 11종<br/>yolo_adapter"]
    D["④ 손상 ↔ 부품 기하 매칭<br/>damage_part_roi_rows"]
    E["⑤ 정규화<br/>pairStatus · searchability"]
    F["⑥ ROI 추출<br/>20% padding → 224 letterbox"]
    G["⑦ DINOv2 임베딩<br/>768d · ImageNet 정규화 · L2"]
    H["⑧ pgvector 코사인 검색<br/>ix_roi_hnsw"]
    I["⑨ 비용 분포 → 견적"]
    J["⑩ 콜백 1회"]

    A --> B1 --> C
    A --> B2 --> C
    C --> D --> E --> F --> G --> H --> I --> J
```

## 분기 — searchability 결정

```mermaid
flowchart TB
    D["손상 검출 1건"]
    Q{"같은 이미지에<br/>고유한 부품 매칭?"}
    Q -->|있음| P["pairStatus: PAIRED<br/>searchability: STRICT<br/>partCode: FRONT_BUMPER"]
    Q -->|없음| V["pairStatus: UNPAIRED<br/>searchability: VECTOR_ONLY<br/>partCode: null"]
    P --> S1["검색: partCode + damageType + 차량"]
    V --> S2["검색: damageType + 차량"]
    S1 --> E1["✓ 견적 항목이 된다"]
    S2 --> E2["✗ 견적 항목이 되지 않는다"]
    D --> Q
```

> 부품을 틀리게 부여하는 것보다 null 이 견적 안전성 측면에서 낫다.
> — `Docs/AI/이미지 입력 및 검색 corpus 결정사항.md`

## 검색 완화 3단계

```mermaid
flowchart TB
    S["768d 질의 벡터 + 메타데이터"]
    S1["① MODEL<br/>WHERE model_id = ?"]
    Q1{"결과 충분?"}
    S2["② PRICE_TIER<br/>WHERE price_tier = ?"]
    Q2{"결과 충분?"}
    S3["③ ALL<br/>차량 조건 없음"]
    R["Top-K (기본 20)<br/>+ fallbackStage 기록"]

    S --> S1 --> Q1
    Q1 -->|예| R
    Q1 -->|아니오| S2 --> Q2
    Q2 -->|예| R
    Q2 -->|아니오| S3 --> R
```

`price_tier` 가 없으면 **추측하지 않고 그 단계를 건너뛴다.**

결과의 `fallbackStage` 는 `estimate_item.ref_condition` 에 저장돼 화면이
"얼마나 비슷한 사례인가" 를 보여 준다.

## 조기 종료 분기

```mermaid
flowchart TB
    I["추론 완료"]
    Q1{"imageResults 가 비었거나<br/>전부 excluded?"}
    Q1 -->|예| R1["PART_NOT_RESOLVED<br/>검색·비용 조회 생략"]
    Q1 -->|아니오| Q2{"남은 이미지에<br/>detection 0건?"}
    Q2 -->|예| R2["NO_DAMAGE_DETECTED<br/>검색·비용 조회 생략"]
    Q2 -->|아니오| S["검색 진행"]
    S --> E["견적 산출"]
    E --> Q3{"estimable = false 이고<br/>INSUFFICIENT_CASES 이고<br/>carClass 있음?"}
    Q3 -->|예| RX["carClass=null 로 재검색·재산정"]
    Q3 -->|아니오| C["콜백"]
    RX --> C
    R1 --> C
    R2 --> C
    I --> Q1
```

**검색·비용 조회는 DB 왕복이다.** 결과가 정해진 경우 건너뛴다.

## 실패 지점

```mermaid
flowchart TB
    S1["① 다운로드"] -->|실패| E1["IMAGE_FETCH_FAILED<br/>retryable: true"]
    S2["② YOLO"] -->|실패| E2["MODEL_ERROR<br/>retryable: true"]
    S3["③~⑤ 검증·정규화"] -->|NormalizationError| E3["INVALID_MODEL_OUTPUT<br/>retryable: false"]
    S4["⑥~⑦ ROI·임베딩"] -->|QueryEmbeddingError| E3
    S5["⑧ pgvector"] -->|VectorSearchError| E4["INTERNAL<br/>retryable: true"]
    S6["⑨ 비용 조회"] -->|CostRepositoryError| E4
    S7["전부 excluded"] --> E5["ALL_IMAGES_EXCLUDED<br/>백엔드 판정"]
    S8["사례 < 2"] --> E6["INSUFFICIENT_CASES<br/>unresolvedParts"]
```

**AI 서버가 콜백에 실을 수 있는 코드는 4종뿐이다.**

## ROI 전처리 상세

```mermaid
flowchart LR
    A["손상 polygon/bbox"]
    B["source_bbox 계산"]
    C["20% padding<br/>PAD_RATIO"]
    D["품질 판정<br/>MIN_SIDE · MAX_ASPECT<br/>part_clipped"]
    E["224px letterbox<br/>종횡비 유지"]
    F["ImageNet mean/std"]
    G["DINOv2 pooler_output<br/>768d"]
    H["L2 정규화"]
    A-->B-->C-->D-->E-->F-->G-->H
```

letterbox를 쓰는 이유는 **종횡비 유지**다. 단순 리사이즈하면 긴 스크래치가 찌그러져
다른 모양이 된다.

L2 정규화하면 코사인 유사도가 내적과 같아져 `vector_cosine_ops` 검색이 정확해진다.

## 모델 구성

```mermaid
flowchart TB
    Y["yolo26n-seg.pt<br/>6.7MB · 학습 시작 가중치"]
    T1["train.py --model damage<br/>60 epoch · imgsz 960"]
    T2["train.py --model damage_part<br/>35 epoch · imgsz 960"]
    M1["damage_best-60ep.pt<br/>23.4MB · 4 클래스 · segment"]
    M2["damage_part_best-35ep.pt<br/>23.4MB · 32 클래스<br/>🔴 실제 task=segment"]
    D["DINOv2-base<br/>revision f9e44c81<br/>이미지에 내장"]

    Y --> T1 --> M1
    Y --> T2 --> M2
```

🔴 **`damage_part_best-35ep.pt` 는 segmentation 가중치다.** API에는 `detect` 로 내보내며,
`AI/server/README.md` 가 "운영 전에는 명세대로 학습한 part detection 가중치로 교체해야 한다"
고 명시했다. 저장소에 교체용 가중치가 없다.

## 확인 필요 항목

- **완화 단계 전환 기준 건수** — "결과가 충분" 의 임계값을 확인하지 못함
- **`roi.py` 상수 실제 값** — `MIN_SIDE` · `MAX_ASPECT` 등 일부 미확인
- **품질 판정이 온라인에 쓰이는지** — corpus 전용인지 확인하지 못함
- **교체용 part detection 가중치** — 저장소에 없음
