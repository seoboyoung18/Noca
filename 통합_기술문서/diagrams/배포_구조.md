## 배포 흐름 (시간순)

```mermaid
sequenceDiagram
    actor D as 개발자
    participant GL as GitLab
    participant R1 as Runner (BE 박스)
    participant R2 as Runner (AI 박스)
    participant BEC as a307-backend
    participant AIC as a307-ai
    participant NGX as Nginx

    D->>GL: develop 머지
    GL->>R1: migration-guard
    R1->>R1: DEPLOY_MARK 이후 SQL 확인
    alt 미적용 SQL 있음
        R1-->>D: 중단 + echo 명령 출력
        D->>D: DB 적용 → 원장 기록 → 재실행
    end
    par 백엔드 + 프론트
        GL->>R1: deploy
        R1->>R1: bootJar → docker build
        R1->>R1: npm ci → npm run build → 번들 검증
        R1->>BEC: docker rm -f && docker run
        R1->>BEC: /actuator/health (최대 120초)
        R1->>NGX: 정적 교체 + reload
    and AI (변경 시)
        GL->>R2: deploy-ai
        R2->>R2: docker build
        R2->>AIC: docker rm -f && docker run
        R2->>AIC: /health 3종 확인
    end
    R1-->>D: 완료
```

## 롤백

```mermaid
flowchart TB
    P["문제 발생"]
    Q{"어느 계층?"}
    Q -->|환경변수| R1["env 수정 + 컨테이너 재생성<br/>⏱ ~1분"]
    Q -->|AI 이미지| R2["docker images a307-ai<br/>이전 SHA 로 재생성<br/>⏱ ~2분"]
    Q -->|백엔드 이미지| R3["docker images a307-backend<br/>이전 SHA 로 재생성<br/>⏱ ~2분"]
    Q -->|프론트| R4["🔴 이전 버전 없음<br/>revert 후 재배포<br/>⏱ 10분+"]
    Q -->|DB 스키마| R5["역방향 SQL 직접 작성<br/>+ 원장 정리<br/>⏱ 수십 분"]
    Q -->|DB 데이터| R6["pg_dump 덤프 restore<br/>⏱ 1시간+"]
    P --> Q
```

**아래로 갈수록 오래 걸리고 위험하다.** 프론트는 `rm -rf` 로 이전 파일을 지워 서버에
남지 않는다.
